Луми 0.1.3 для Windows x64

Запуск
1. Закройте прежнее окно Луми и откройте Lumi-0.1.3-Windows-x64.exe двойным щелчком.
2. Дождитесь открытия окна. Отдельно устанавливать Node.js не требуется.
3. При первом запуске придумайте родительский пароль. Коды детей из 6 цифр
   создаются автоматически. Сохраните их из окна, которое появится после настройки.
4. После настройки выберите профиль ребёнка и начните занятие.

Новый профиль тоже получает код автоматически. Если код забыт, войдите как
родитель, откройте настройки профиля, отметьте «Создать новый код при сохранении»
и сохраните профиль. Новый код заменит прежний и появится в отдельном окне.
У существующих профилей прежние коды сохраняются после обновления приложения.

Тестовый кабинет на компьютере
Откройте ярлык «Луми - тест ребёнка» на рабочем столе или в «Загрузках».
Он запускает это же Windows-приложение с отдельными тестовыми данными.
При обычном запуске EXE открывается ваша семья. Тестовый режим использует
папку %APPDATA%\Lumi-Demo и доступен только на этом компьютере.

В программе уже есть 60 мини-уроков, 180 заданий, черновики с проверкой
арифметики, комментарии родителя, тетради для печати и 11 файлов библиотеки.
Это стартовая подборка, не полная школьная программа.

Данные семьи сохраняются отдельно от EXE:
%APPDATA%\Lumi\data\family.json
Замена EXE на новую версию не удаляет эту папку. Перед обновлением можно
закрыть Луми и сохранить личную резервную копию папки data.

Чтобы открыть Луми на Android, выберите «Справка» > «Подключить Android».
Телефон и компьютер должны быть в одной домашней сети. Окно Луми на компьютере
должно оставаться открытым. При запросе Windows разрешайте сетевой доступ
только для доверенной домашней сети.

Полные ответы доступны родителю. Перед передачей общего компьютера ребёнку
закройте родительский вход и отдельные окна с ответами.

Электронные дневники не подключены. Реальная модель ИИ не включена;
обычные уроки, тесты, подсказки и проверка вычислений работают без неё.
Фото сохраняются для взрослого, автоматического чтения почерка пока нет.

Фактическая проверка выполнена на Windows 11 x64. Сборка не подписана
сертификатом издателя.
