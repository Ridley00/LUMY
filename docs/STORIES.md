# Интерактивные истории Луми

Подготовлено 11 октября 2026 года. Изменены только content/stories.json и этот документ.

## Состав

В наборе 3 оригинальные короткие истории, 18 сцен и 9 вопросов. В каждой истории 6 сцен, из них 3 с вопросами. Вопросы находятся в сценах 2, 4 и 5; завершающая сцена имеет настроение celebrate.

| История | ID | Уровни | Тема |
|---|---|---|---|
| Пикник для светлячков | firefly-picnic | 0, 1, 2 | Сложение, вычитание, сравнение количеств |
| Карта лунного сада | moon-garden-map | 3, 4, 5, 6 | Порядок действий, пространственная инструкция, наблюдение и догадка |
| Сообщение на игровой станции | game-station-message | 2-11 | Подозрительные просьбы, установка, покупки, личные данные |

Каждый уровень от 0 до 11 входит хотя бы в одну историю. Уровни служат ориентиром выбора. Параметрического изменения задач по классу нет. Для дошкольников текст и варианты читает взрослый; считать можно на пальцах или с фишками. История по безопасности является вводной тренировкой общих правил, а не отдельной сложной программой для каждого старшего класса.

Во всех историях участвуют:

- lumi: Луми, добрый исследователь с ушами-листочками.
- tish: Тиша, любопытный совёнок. Он может ошибиться, остановиться и проверить себя.
- mira: Мира, лисичка, которая рисует и помогает формулировать понятные инструкции.

Все сюжеты, диалоги и задания написаны для этого набора. Название игры «Лесные острова» используется как вымышленный пример, без рекомендации к установке.

## Контракт

Верхний уровень: version: 1 и stories[].

История содержит только согласованные поля:

- id, title, summary;
- levels - массив чисел от 0 до 11;
- reward: 6;
- coverCharacter: lumi, tish или mira;
- sceneLabel - название места;
- scenes - упорядоченный массив сцен.

Сцена:

- id - уникальный идентификатор;
- speaker: lumi, tish или mira;
- mood: idle, thinking или celebrate;
- text - реплика персонажа;
- question - необязательный объект вопроса.

Вопрос:

- prompt - условие;
- options - массив из трёх строк;
- answer - **число, индекс options с нуля**, в отличие от строкового ключа в courses.json;
- feedbackCorrect - строка объяснения после правильного ответа;
- feedbackWrong - строка мягкой подсказки для новой попытки.

Пример интерпретации: answer: 2 означает третий вариант. Вопрос принадлежит сцене; отдельный ID внутри question не вводился.

## Переходы и награда

Контент рассчитан на следующий ход интерфейса:

1. Сцена без question продолжается кнопкой.
2. В сцене с question пользователь выбирает один вариант.
3. Неверный выбор показывает feedbackWrong и оставляет ребёнка в той же сцене. Можно попробовать снова без стыда, потери прогресса или ограничения числа попыток.
4. Верный выбор показывает feedbackCorrect и разрешает переход дальше.
5. После успешных ответов на все три вопроса доступна заключительная сцена.

reward: 6 задан по согласованному контракту у каждой истории. Проверку завершения и начисление выполняет сервер. Сама последняя реплика или mood: celebrate не является доказательством выполнения заданий. Защита от повторного начисления, обхода сцен и одновременных запросов должна проверяться на уровне приложения.

Исходный JSON содержит ключи и правильные объяснения. Не раздавать его статически целиком. До ответа детский API должен возвращать условие и варианты без answer; корректирующее объяснение выдаётся по результату серверной проверки. Состояние «правильно» нельзя принимать только со стороны браузера.

## Педагогические границы

Неправильный вариант получает действие для проверки: разложить предметы, сравнить шаги, отделить наблюдение от предположения. Реплики не объявляют ребёнка невнимательным, плохим или неспособным и не требуют угадать мнение взрослого.

В историях нет обещаний диагностировать знания, повысить оценку или гарантировать цифровую безопасность. Успешное прохождение означает завершение этих девяти локальных вопросов. Материалы не заменяют школьный курс или независимую оценку навыков.

История по безопасности не требует настоящих ссылок, аккаунтов, паролей, кодов, адресов, установок или покупок. Не предлагается отключать защиту. Цена 90 рублей относится только к вымышленному набору внутри сюжета.

Тексты не содержат готовых изображений, анимации, озвучки или эффектов. Их подключает интерфейс по speaker, mood, coverCharacter и sceneLabel.

## Проверка содержания

Локальная проверка Node.js завершилась с ok: true:

- 3 истории, ровно 18 сцен и 9 вопросов;
- 21 уникальный ID между историями и сценами;
- все уровни 0-11 представлены;
- в каждой истории присутствуют все три персонажа;
- допустимые speaker, coverCharacter и mood;
- все варианты уникальны в пределах вопроса;
- answer в каждом вопросе является допустимым числовым индексом;
- все реплики, условия и обе обратные связи непустые;
- у всех историй reward: 6;
- отдельно пересчитаны 4 + 2 = 6 и 6 - 2 = 4;
- сравнение двух групп по три предмета проверено по условию;
- длинного тире в JSON нет.

Проверка сцен и переходов в браузере, серверных ответов, наград, доступности и эффектов в этот этап не входит.

Повторить основную проверку из папки LUMI:

~~~powershell
@'
import fs from 'node:fs';
import assert from 'node:assert/strict';
const data = JSON.parse(fs.readFileSync('content/stories.json', 'utf8'));
const ids = new Set();
const levels = new Set();
let scenes = 0;
let questions = 0;
for (const story of data.stories) {
  assert(!ids.has(story.id)); ids.add(story.id);
  assert.equal(story.reward, 6);
  assert.equal(story.scenes.length, 6);
  for (const level of story.levels) levels.add(level);
  let localQuestions = 0;
  for (const scene of story.scenes) {
    assert(!ids.has(scene.id)); ids.add(scene.id);
    assert(scene.text);
    scenes += 1;
    if (!scene.question) continue;
    const q = scene.question;
    assert(Number.isInteger(q.answer));
    assert(q.answer >= 0 && q.answer < q.options.length);
    assert(q.prompt && q.feedbackCorrect && q.feedbackWrong);
    assert.equal(new Set(q.options).size, q.options.length);
    localQuestions += 1;
    questions += 1;
  }
  assert.equal(localQuestions, 3);
}
assert.equal(data.version, 1);
assert.equal(data.stories.length, 3);
assert.equal(scenes, 18);
assert.equal(questions, 9);
assert.equal(levels.size, 12);
console.log({ ok: true, stories: data.stories.length, scenes, questions, uniqueIds: ids.size });
'@ | node --input-type=module
~~~
